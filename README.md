# Napkin

Back-of-the-napkin math for your desktop. Napkin is an open-source calculator notepad in the
spirit of [Numi](https://numi.app): type calculations in plain words, read the answers on the
right.

```
# Trip
Hotel: 3 nights * €89            €267
Train: $120 in EUR               €107.69
Total: sum                       €374.69
20 inches in cm                  50.8 cm
New York time                    08:00
```

Built in Rust with [GPUI](https://www.gpui.rs). Work in progress; see `docs/spec.md`.
