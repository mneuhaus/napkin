# Romanian (română). Format: see crates/napkin-core/src/vocab.rs.
# Romanian puts `de` between a number from 20 on and the noun (`20 de ore`, `100 de lei`): the
# `other` display forms carry it, and the common unit and currency words accept it. Many people
# type without diacritics or with the older cedilla letters (ş, ţ), so the everyday words accept
# those spellings too.
