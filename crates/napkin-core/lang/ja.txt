# Japanese (日本語). Format: see crates/napkin-core/src/vocab.rs.
#
# Japanese is written without spaces: every kanji and kana is a token of its own and the longest
# known phrase wins (`5キロメートル`, `5インチをセンチ`). Characters this file does not know stay
# prose. Numbers are written in digits; kanji numerals (`二十`) are prose.

# Arithmetic. `の` puts the base first (`50の20%` is 20% of 50, so it multiplies).
plus = 足す, たす, 足して, プラス, 加算
minus = 引く, ひく, 引いて, マイナス, 減算
times = 掛ける, かける, 掛けて, 乗算, の
divide = 割る, わる, 割って, 除算
per = 毎, あたり, 当たり, につき
# `5インチをセンチに`, `9ドルをユーロで`, `5インチは何センチ`: the particle after the target is
# prose.

# `価格は500円`
