# Phrases of Numi's Norwegian vocabulary that Napkin reads differently on purpose.
# key<TAB>phrase<TAB>reason
divide.variants	subtrahert	means subtracted; Napkin reads it as minus (`6 subtrahert 3` = 3); divide with `delt på`
divide.variants	subtrahert med	means subtracted by; Napkin reads it as minus; divide with `delt med`
divide.variants	subtrahert på	means subtracted; divide with `delt på`
billion.variants	billion	Norwegian uses the long scale: a billion is 10^12; 10^9 is `milliard`
billion.variants	Billion	Norwegian uses the long scale: a billion is 10^12; 10^9 is `milliard`
thousand.variants	th	would turn ordinals into thousands (`5th` = 5000)
thousand.variants	th.	would turn ordinals into thousands (`5th.` = 5000)
are.variants	a	`a` is the English article (`5 a day`, `as a % of`); ares are `ar`/`are`
nautical_mile.variants	nm	`nm` stays the nanometre; nautical miles are `nmi`/`nautisk mil`
cbcm.variants	cm	`cm` is the centimetre; cubic centimetres are `cm³`/`cc`
BYR.variants	Belarusian ruble	BYR is the rubel before 2016 (10,000 BYR = 1 BYN), a code Napkin does not know; the name reads as today's BYN
BYR.variants	Belarusian rubles	BYR is the rubel before 2016 (10,000 BYR = 1 BYN), a code Napkin does not know; the name reads as today's BYN
BYR.variants	bel. ruble	BYR is the rubel before 2016 (10,000 BYR = 1 BYN), a code Napkin does not know; the name reads as today's BYN
BYR.variants	bel rubles	BYR is the rubel before 2016 (10,000 BYR = 1 BYN), a code Napkin does not know; the name reads as today's BYN
inch.variants	"	`"` opens quoted text, which Napkin skips as a comment; inches are `″`, `in` or the word
